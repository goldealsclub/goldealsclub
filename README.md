# Goldeals Club

Crée un site web premium de deals mode et streetwear nommé GOLDDEALS CLUB.

Le concept du site :

GOLDDEALS CLUB est une plateforme de bons plans mode inspirée du fonctionnement de Dealabs, mais spécialisée dans la mode, le streetwear, les sneakers et les accessoires. Le site ne vend pas directement les produits. Il sélectionne et affiche les meilleures promotions trouvées chez des vendeurs fiables, puis redirige l’utilisateur vers le site du vendeur original.

Je veux un site en français par défaut, avec la possibilité de proposer plusieurs langues, au minimum :

- Français

- Anglais

- Espagnol

Je veux un design très chic, minimaliste, premium et mode, inspiré de Zara, des sites éditoriaux haut de gamme et des concept stores, avec une légère touche streetwear. Je veux aussi une structure fonctionnelle inspirée des sites de deals comme Dealabs, mais avec une esthétique beaucoup plus luxe, élégante et mode. Je ne veux pas un site discount cheap, ni un style marketplace agressif, ni un rendu bas de gamme. Je veux un effet “super promo mais chic”.

Le site doit transmettre :

- élégance

- confiance

- modernité

- goût mode

- rareté

- qualité

- bonnes affaires haut de gamme

Direction artistique :

- design luxe minimaliste

- style mode premium

- inspiration Zara, magazine mode, concept store haut de gamme

- touche streetwear discrète et raffinée

- ambiance sobre, chic, élégante, tendance

- palette de couleurs : noir, blanc cassé, beige, ivoire, taupe, gris doux

- typographie élégante, moderne, raffinée

- interface claire, épurée, premium

- beaucoup d’espace blanc

- hiérarchie visuelle forte

- look éditorial premium

- design responsive mobile-first

- pas de rouge agressif

- pas de couleurs flashy

- pas d’effet discount bas de gamme

Je veux que les promotions soient mises en valeur avec style, comme des opportunités premium, pas comme des soldes cheap. Le site doit mélanger l’élégance d’un site de mode haut de gamme avec l’impact visuel d’un site de bons plans.

Le site doit avoir une vraie logique de plateforme de deals :

- les utilisateurs peuvent consulter les deals

- enregistrer un deal en favori

- partager un deal sur les réseaux sociaux

- copier le lien du deal

- voir les catégories

- voir les meilleures promos du moment

- voir les deals les plus populaires

- voir les deals récents

- filtrer les deals

- trier les deals

Je veux que les flammes soient élégantes, bien intégrées au design, pas cheap ni trop cartoon. Elles doivent servir de repère visuel comme sur les sites de deals, mais en version chic et raffinée.

Je veux une hiérarchie visuelle des deals :

- promo standard = 1 flamme

- super promo = 2 flammes

- deal du jour / sélection forte = badge spécial “Super Deal”, “Deal du jour”, “Best Pick” ou “Sélection Gold”
